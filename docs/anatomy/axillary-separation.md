# 겨드랑이 외피와 신경 부착 보정

2026-09-25. 전신 트윈의 오른손 인사·재즈댄스에서 나타나던 옆구리 늘어짐 수정.

## 원인

실제 `skin-atlas-web.glb`는 저장된 `_RIG_INDEX`와 `_RIG_WEIGHT`를 사용한다. 이전 `weightsAt(..., surface=true)` 변경은 이 로딩 경로에 적용되지 않았다. 이전 회귀 검사도 별도 외피 등록과 재바인딩을 수행하여 실제 GLB의 오류를 검출하지 못했다.

원본 외피에는 상완 내측과 흉곽 외측의 접촉면이 합쳐진 구간이 있었다. 이 구간은 팔을 들면 피부막처럼 늘어난다. 신경의 최근접 피부 부착 역시 서로 가까운 팔과 몸통의 반대편 표면을 선택할 수 있었다.

## 구현

- Blender Boolean으로 겨드랑이 아래의 접촉면을 분리하고 절개 영역을 닫힌 표면으로 만든다. 어깨 위쪽의 연결은 유지한다. 새 면은 변형에 필요한 해상도로 나눈다.
- 분리된 메시 연결 성분으로 팔과 몸통을 판별한다. 팔꿈치의 기존 본 가중치 비율은 보존하고 옆구리는 몸통 본에 귀속시킨다. 어깨 접힘 끝에서는 공간적으로 부드러운 가중치 전이를 사용한다.
- 결과는 GLB에 저장한다. 런타임에 Boolean이나 외피 재바인딩을 실행하지 않는다. 피부 요청 버전은 `native=3`이다.
- 신경 피부 부착 검색은 어깨 주변에서 팔 본 영향도가 다른 표면을 제외한다. 신경의 척추 기시부는 유지한다. 삼각형 사이의 곡률 오차 여유를 포함해 시각화용 피부 안쪽 간격을 3mm에서 5mm로 늘렸다. 이 간격은 환자별 해부학 측정값이 아니다.
- 외피 변경에 따라 침대·의자 접촉 표본을 재생성한다.

## 재생성

웹 프로젝트 루트에서 새로 내보낸 원본 아틀라스 외피에 실행한다. 이미 보정된 파일에는 중복 적용하지 않는다. 이전 원본에서 다시 생성하려면 `SKIN_SOURCE`를 지정한다. macOS 기본 Blender 경로 이외에는 `BLENDER_PATH`를 지정한다.

```sh
node scripts/repair-atlas-axilla.mjs
node scripts/build-bed-support.mjs
node scripts/build-seat-support.mjs
```

원본 외피의 다른 부분은 유지한다. 피부 삼각형은 약 11만 개에서 약 14.4만 개로 증가하므로 앞으로 LOD를 만들 때 새 겨드랑이 접힘과 분리 경계를 보존해야 한다.

## 검증 방법

`tests/native-skin.test.mjs`는 화면에서 읽는 GLB의 본 가중치를 그대로 사용하여 인사/재즈 각 32개 자세의 국소 모서리 늘어짐과 옆구리 고정을 확인한다. 팔꿈치처럼 원래 큰 삼각형과 겨드랑이의 짧은 모서리를 구분해 허용 범위를 설정한다. 기존 발·손·보행 검사도 유지한다.

`tests/nerve-skin.test.mjs`는 런타임이 저장한 `nerveSkinFace`와 `nerveSkinAnchor`를 검사한다. 검사 중 최근접 부착을 다시 계산하지 않는다. 신경 표본 12,366개에 인사·재즈·걷기·달리기·침대·정지 자세를 적용하고 외피 돌출과 척추 기시부 이동을 확인한다. 모든 신경 정점의 모든 순간에 대한 증명은 아니다.

브라우저 시각 검증은 `POSE_QA=1 node scripts/profiling/body-profile.mjs`로 실행한다. 불투명 피부와 반투명 피부+신경 화면을 `outputs/axilla`에 저장한다. 독립된 실제 AnatomyScene을 사용하는 검사이며 배포 페이지나 전체 React UI 검사와는 구분한다.

최종 결과: 외피/어깨/침대/의자 회귀 검사 14개 통과, 신경 검사 2개 통과(12,366개 표본, 보정 후 외피 돌출 0개, 척추 기시부 이동 0), TypeScript 검사 및 프로덕션 빌드 통과. 공개 사이트 배포와 Git 커밋은 이번 작업에 포함하지 않았다.
