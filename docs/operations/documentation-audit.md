## 웹 매뉴얼 분리

`docs/manual`에는 시작·전신·손목·피부 조작을 둡니다. 설치 안내 원본은 `docs/operations/demo-guide.md`입니다. 빌드 스크립트가 이 다섯 원본을 `/manual` 페이지 콘텐츠와 다운로드용 Markdown으로 생성하므로 이중 편집하지 않습니다.

해부학 재생성·운동학·과거 자산 문서는 개발·연구 문서로 유지합니다. 웹 사용자 매뉴얼에는 실행과 조작에 필요한 내용만 옮겼습니다. 검증의 실제 환경과 미검증 환경은 [데모 검증 기록](demo-validation.md)에 명시합니다.

`npm run docs:check`로 상대 파일 링크의 존재와 매뉴얼 5개·웹 콘텐츠 JSON의 원본 일치를 재현 가능하게 검사합니다. `scripts`에는 Markdown 문서가 없습니다. 문헌의 외부 링크·최신 의학 근거, 브라우저 시각 검증 및 GPU 성능 재측정은 이번 문서 점검에 포함하지 않았습니다. 기존 테스트 통과 기록은 보존하며 문서 수정만을 위해 전체 생체 모델 회귀 검사를 재실행하지 않습니다.

후속 확인 항목은 실제 Windows 설치·실행, 현재 버전의 기기별 FPS·로딩 프로파일, 연구 계획에 명시한 물리·임상 검증입니다. 기존 배포 데모는 이전 패키징 시점의 문서를 포함하며 이번 소스 문서 정리로 배포 ZIP을 다시 만들지는 않습니다.

## 공개 문서 정리와 웹 뷰어 — 2026-09-14

연구 원본·매뉴얼·생성 콘텐츠에서 개인 절대 경로, 내부 저장소·모듈 참조, 내부 실험 결과·하드웨어 핀 매핑, 상세 커밋·작업 시각을 제거했습니다. 코드 감사는 공개 기능과 통합 범위 설명으로, 상세 Git 기록은 기능 변경 요약으로 교체했습니다. 배포에 포함되는 인계 문서와 공개 소스 manifest도 개인 경로·배포 식별자가 노출되지 않도록 정리했습니다. 공개 학술 출처와 이용 조건은 유지합니다.

연구 10개·매뉴얼 5개를 `/documents/{collection}/{slug}` 웹 뷰어로 제공합니다. 원본은 엄격한 UTF-8 디코딩으로 읽고 웹 문서·목차·표·코드로 표시합니다. 다운로드는 UTF-8 Content-Type과 BOM을 명시합니다. 임의 파일 경로는 받지 않고 빌드한 문서 목록에서만 선택합니다. HTML은 실행하지 않으며 안전한 링크만 만듭니다.

전체 99개 테스트, TypeScript 검사와 사이트 빌드를 통과했습니다. 실제 로컬 Worker에서 문서 15개·다운로드 15개의 응답, 한글·표 표시용 HTML, UTF-8 바이트, 내부 문서 이동, 없는 다운로드의 404를 확인했습니다. 브라우저 시각 QA는 포함하지 않습니다. Git의 과거 객체와 이미 외부에 전달된 파일은 현재 배포본 수정으로 삭제되지 않습니다.
