- 메뉴·썸네일·열기 링크를 기본 HTML 링크로 변경하여 독립 시뮬레이터를 문서 탐색으로 연다.

## 손목 회전 조작과 요골동맥 색상 보정

- 중앙의 화면 Z 회전을 Y축 좌우 회전으로 대체했다. 중앙은 수평 회전만, 주변은 수평 회전과 위아래 기울기를 제공한다. 기존 수평 드래그의 부호를 바꾸고 두 영역에 동일한 함수를 사용한다. 해부학 보기와 조직 절단면 모두 적용한다.
- 요골동맥 관을 `#ff0000`으로 강조하고 흰 반사광을 줄였다. 조직 단면의 밝은 혈관벽도 빨간 계열로 변경한다.
- 중앙/윗부분 드래그의 방향 일치, 수평 회전 중 기울기 고정, 패치 드래그 우선순위 및 요골동맥 재질을 확인했다. 전체 테스트 93/93, TypeScript 검사·빌드 성공. 브라우저 시각 QA는 포함하지 않았다.

## 혈관 연결과 손목 작업 공간 정리

- 요골동맥의 잘린 중심선 관 대신 원본 distal 경로와 손바닥 동맥궁 접속을 복원했다. 동맥망에 공유하는 C2 위치 변형과 맥동장을 적용하며 전완·손의 끝을 고정한다. 위치 조절 때 접속부를 따로 평행 이동하지 않는다. 굽힘 구간을 세분하고 변형의 역전치로 표면 법선을 보정한다. 이는 공간 근사이며 재료 기반 FEM은 아니다.
- ±6 mm 좌우/깊이 조합과 0/60 µm 맥동에서 실제 GLB 접속점 쌍의 거리가 0.25 mm 이내(원본 약 0.184 mm)임을 검사했다. 이는 원본 별도 메시 접속의 유지 검사이며 watertight 결합을 뜻하지 않는다. distal 고정·중간 이동·리셋 복원·유한 좌표·맥동도 검사했다.
- 신호 생성, 스냅샷, 단면과 3D가 위치 완화 함수를 공유한다. 요골동맥 두 슬라이더를 전극 설정에서 3D 바로 아래 조직 옵션으로 이동했다.
- 페이지 소개 헤더를 제거하고 남은 높이를 iframe에 배정했다. Radial Artery Digital Twin 개요는 명시적 접기·펼치기 버튼과 로컬 상태 기억을 제공한다. 3D 영상 영역은 1:1 종횡비이며 옵션 높이는 별도이다.
- 전체 93개 테스트 및 TypeScript 검사 통과. 브라우저 시각 QA는 포함하지 않는다.
