# User Guide

Updated: 2026-09-15. SOMA is a research simulator for whole-body anatomy and synthetic wrist biosignals.

## Getting started

1. Open Whole-body Twin or Wrist Sensing from the top navigation.
2. Select anatomical systems, motion and sensor sites in the whole-body view; adjust posture and electrode placement in the wrist workspace.
3. Compare waveforms with tissue displacement. Distinguish display magnification from actual model values.
4. Record the experimental settings and export the required data.

## Workspaces

- Whole-body Twin: explore anatomical systems, locomotion, clinical task animations, local skin sections and sensor sites.
- Wrist Sensing: compare the atlas wrist, flexible electrode arrays, capacitance/PPG waveforms and analytical results.
- Research: review implemented scope, continuous-BP designs, references and validation plans.
- User Guide: installation, operation, controls and troubleshooting.

## Reading documents

Research cards and guide document icons open the web reader. Use its contents list, tables and code blocks. Choose Download Markdown for a UTF-8 copy in the selected language.

## Interpreting results

BP, SpO₂ and other displayed estimates must be interpreted in the context of the synthetic model or loaded recording. Detailed anatomical appearance does not establish patient-specific physiology or clinical accuracy. The research documents distinguish current MRC analysis from planned MVDR and ECG-PAT continuous-BP extensions.

## Language

Use 한국어 / EN in the header. The choice is saved in the same browser and applies to other workspaces and documents. Changing language reloads the page, so export any required experimental data first. Web documents and Markdown downloads follow the selected language.
