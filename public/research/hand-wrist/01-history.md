# 01. 개발 이력과 현재 기능

기준: 2026-09-13. Git에 남은 변화는 [별도 이력](git-history.md)에 전체 SHA와 함께 기록했다. 초기 얼굴·외피 시도는 현재 구현과 혼동하지 않도록 아래에 구분한다.

## 센서·피부 실험 및 UI

- 센서 위치: 손목, 손가락, 귓볼, 이마, 흉부, 상완. 여러 위치를 켜거나 전부 끌 수 있다.
- ECG, PPG, EEG, EMG, 호흡, CAP 합성 채널 및 CSV. 센서 모달리티에 따라 설정과 파형을 전환한다.
- 좌우 패널 접기/펼치기, Active Sensor 닫기, 왼쪽 스크롤 공간 예약, 운동 버튼 재배치.
- 피부계에서 12개 국소 영역을 선택하고 중앙 모달에서 3D 절단면을 관찰한다. 표피·진피·지방, 혈관, 지역별 뼈·근육·힘줄을 표시한다.
- 요골동맥 주위 융기/주변 하강, 손목 곡면, 넓어진 길이 방향 창, top-view 격자와 등고선. 깊은 지지체 제약을 포함한다.
- 광선은 교육용 경로와 흡수 그림이다. 전신 페이지의 SpO₂는 입력 조건이며 측정 정확도가 입증된 역추정이 아니다. 비침습 혈당 추정은 구현하지 않았다.

## 자세·동작

일어서기, 반복 앉았다 일어서기, 손 쥐기, 침대 눕기 추가. 앉을 때 실제 피부 지지점으로 의자 관통을 제한한다. 침대는 서 있는 환자 뒤쪽에 놓인다. 왼쪽 가장자리에 앉고 한 손으로 지지한 뒤 옆으로 내려가 다리를 뻗고 반듯하게 눕는다. 최종 수정은 왼팔을 미리 뻗어 몸과 함께 내려놓는 동작이다. 원위 관절의 꺾임·손목 뒤집힘을 줄이고 눕기 확대 시 바운딩 구의 소실을 보정했다.

편안 모드는 기본 ON이며 외부 생식기 영역만 가린다. 임의 덮개 구체를 추가하지 않는다. 뼈·근육·피부는 공통 리그를 따른다. 동작별 CSV에 동작 단계·반복·노력도 등이 기록된다. 현재의 노력도는 생리적 운동 부하 검증 결과가 아닌 입력/합성 곡선이다.

`body_3d/video/linkedin/`에 영상과 제작 스크립트를 보관했다.

| 결과물 | 내용 |
|---|---|
| `SOMA-LinkedIn-Highlights-v3.mp4` | 최신: 55초, 1080×1350, 30 fps, H.264/AAC |
| 달리기 36–44초 | 기존 4초에서 8초로 연장; 카메라 약 90° 회전; 불투명 근육에서 점차 투명해져 내부 계통 노출 |
| 나머지 장면 | 전신·순환·파형·피부 단면·걷기·손 쥐기·침대 동작 |
| 커버·자막·음악 | JPEG, SRT, 합성 음악 및 재현 스크립트 |

이 파일은 제작 완료 자료이며 LinkedIn에 대신 게시하거나 메시지를 발송한 기록은 없다. 영상은 실제 SOMA 렌더 코드를 사용하는 촬영용 레이아웃으로 제작했다.

## 변경 시 보존할 원칙

현재 피부는 `skin-atlas-web.glb`, 바인딩은 같은 해부학 좌표계다. 역사적인 외피/리깅을 무심코 복구하지 않는다. 관절 동작을 메시 절반 분할·비균일 스케일로 대체하지 않는다. 지면·의자·침대 지지는 실제 네이티브 피부 샘플을 유지한다. 피부와 센서 표시는 선택 사항이며 편안 모드는 켠 상태로 시작한다.
