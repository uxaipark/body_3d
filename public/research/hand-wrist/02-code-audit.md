# 02. 시뮬레이터 구성과 통합

## 현재 구성

| 구성 | 기능 | 해석 범위 |
| --- | --- | --- |
| 전신 뷰 | 해부학 계통·관절 동작·피부 표시 | 아틀라스 기반 가상 모델 |
| 손목 뷰 | 뼈·근육·힘줄·혈관·신경·피부와 곡면 패치 | 개인별 영상 정합 전의 대표 구조 |
| 합성 신호 | 심장·정전용량·광학·동작 관련 채널 생성 | 입력 조건에 따른 시뮬레이션 |
| 분석 | MRC, 파형·지연·혈압·SpO₂ 비교 | 합성 모델의 분석 결과이며 임상 성능은 미검증 |
| 데이터 흐름 | 별도 Worker에서 신호를 생성하고 화면에 전달 | 표시 파형과 분석용 원본 샘플을 구분 |

## 조직과 센서의 연결

혈관 압력에 따른 반경 변화가 인과적 조직 이완과 표면 변위로 연결됩니다. 전극의 위치·면적·접촉 조건을 반영해 정전용량 채널을 생성합니다. 3D의 표시 확대는 시각화에만 적용하며 신호 값을 확대하지 않습니다.

패치와 동맥 위치를 변경하면 3D·단면·스냅샷·신호 모델이 같은 좌표를 사용합니다. 기하학적 일치가 실제 조직 물성이나 접촉 정확도를 보장하지는 않습니다.

## 분석 시 주의점

- 파형 정렬·결합과 지연 측정에 필요한 신호 경로를 구분합니다.
- 화면 표시를 위해 줄인 샘플을 시간 지연 분석의 원본으로 사용하지 않습니다.
- 합성 참조값은 평가에 사용하며 실제 추정기의 관측 입력과 분리합니다.
- 필터의 인과성·군지연, ADC 채널 간 시각 차이, 좌표 단위를 명시합니다.
- 같은 합성 관계로 생성하고 역산한 결과를 실제 혈압·SpO₂ 정확도로 해석하지 않습니다.

## 확장 범위

MVDR, 실제 ECG 프레임, PAT·PTT·PEP 분리, 환자별 손목 정합과 독립 데이터 검증은 [신호 파이프라인 설계](05-signal-pipeline.md)와 [검증 계획](06-validation.md)을 따릅니다.
