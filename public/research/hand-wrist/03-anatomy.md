# 03. 손·손목 해부학 수집 및 3D 모델링 명세

## 해부학 단위

손목 패치 중심만 확대하면 손가락 굴곡·전완 회전·근위 혈관 전달을 놓친다. 모델 범위를 원위 전완–수근–중수–수지 전체로 잡고 센서 주위 30–60 mm를 고해상도 영역으로 둔다. 아래는 모델링 체크리스트이며 모든 항목이 현재 분할·물성화되었다는 뜻은 아니다.

| 구역 | 포함할 구조 | 센싱에 미치는 영향 |
|---|---|---|
| 뼈·관절 | 원위 요골·척골, 수근골 8개, 중수골 5개, 지골 14개; 요수근·중수수근·MCP/PIP/DIP | 표면 곡률·고정 경계, 센서의 반력, 관절 자세에 따른 혈관·건 위치 |
| 굴근 | FDS 4건, FDP 4건, FPL, FCR, FCU, PL; 방형회내근과 근위 근복 | 손 쥐기 시 힘줄 이동·피부 변형·EMG 및 압력 아티팩트 |
| 신근 | 6개 신전건 구획, 신전지대, ECU·EDC·EPL·APL/EPB 등의 건 | 손목 신전·회전의 부위별 변형과 지지 |
| 손바닥 | 무지구·소지구, 충양근·골간근, 수장건막, 굴곡건 풀리 | 손가락 센서 착용과 굴곡 시 접촉력 |
| 혈관 | 요골·척골동맥, 수장/배측 수근 분지, 얕은/깊은 수장궁, 공통/고유 수지동맥, 동반·표재 정맥 | 실제 전파 경로, 반사파, 위치별 기계/광학 신호 |
| 신경 | 정중·척골·요골의 원위 가지, 수지 신경 | 해부학 위치 경계 및 미끄럼. 단순 노란 메시가 전기 신경 모델은 아님 |
| 피부 | 각질층·생활 표피·유두/망상 진피, rete ridge, 혈관총·땀샘·땀관 | 파장별 흡수/산란, 표면 접촉, 수분·유전율 |
| 피하조직 | 지방 소엽, 섬유 격막, 표재/심부 근막, 표재 정맥 | 맥동 전달·전단·비선형 탄성·점탄성 지연 |
| 손끝 | 지문면, 지방 패드·섬유 격막, 손톱·조상·말절골, 양측 수지혈관 | 투과형과 반사형 광경로, 센서 압박에 따른 관류 변화 |

수근관은 굴곡건들과 정중신경의 위치를 분명히 표시한다. FCR은 별도 골섬유성 통로로 구분하고, 요골동맥을 수근관 중앙에 넣지 않는다. 척골신경·동맥의 Guyon관도 수근관과 구분한다. 신전면과 굴곡면의 지대·건초를 따로 모델링한다. 명칭·경계의 문헌 차이는 초음파 단면 위치와 함께 기록한다. [RadioGraphics 손목 초음파 해부학](https://pubs.rsna.org/doi/10.1148/rg.256055028), [상지 신경의 영상 표지](https://pubs.rsna.org/doi/10.1148/rg.2016150088).

요골동맥은 원위 전완에서 FCR과 상완요골근 쪽 구조 사이를 지나며 이후 손목의 요측·배측으로 돌아 수장궁과 연결된다. 패치 좌표의 직선 X축을 전체 동맥 경로로 사용하지 않는다. 분지와 변이를 독립 시나리오로 둔다. [고해상도 초음파 전완 혈관 구획 연구](https://pubmed.ncbi.nlm.nih.gov/34866700/), [요골동맥 변이 연구](https://pubmed.ncbi.nlm.nih.gov/23197145/).

|---|---|---|

| 원위 요골동맥 | 2021 젊은 성인 pilot, 96명; 우측 경상돌기 부위 직경 1.42±0.26 mm, 피부까지 거리 4.00±1.20 mm | 다른 집단·부위·자세이므로 위 값과 합쳐 ‘정상 손목’ 하나로 만들지 않음 |
| 이번 아틀라스의 깊이 | crease 부근 volar 축 투영 간격 약 10.67 mm | 직접 메시에서 계산한 값. 최단 법선 깊이나 위 초음파 값과 동등하지 않음; 측정 정합 미완료 |

| 지방 두께 | UI 0.5–6 mm; 초기 2.2 mm | 감도 탐색 범위. 인구 정상 범위나 피험자 측정값이라는 뜻 아님 |
| 표피·진피 두께 | 지역별 대표 파라미터 | 피부 부위·압박·연령에 따라 바꾸고 실제 초음파/조직 자료와 매칭할 것 |

출처: [2015 요골동맥 초음파](https://pubmed.ncbi.nlm.nih.gov/26013978/), [2021 pilot 논문](https://www.sciencedirect.com/science/article/pii/S0940960221000893). 인구 분포를 시뮬레이션할 때 직경·깊이·성별·신장·BMI를 독립 정규분포로 무조건 추첨하지 않는다. 조건부 상관관계와 원자료 모집단을 보존한다.

## 정합·메시 명세

현재 전신 좌표는 m, Y-up이다. 오른손 추출은 같은 원본에 강체 좌표 변환 `[.920-y, z-.019, -x-.276]`만 적용한다. 손목 뷰는 X 원위 방향, Y volar 표시 방향, Z 요측, 1 mm=0.001 world unit이다. 피부의 팔 가중치로 하체 조각 혼입을 제거하고 전완 절단 평면을 통과하는 삼각형은 평면에서 정확히 잘라낸다. 뼈는 실제 원본 형상을 유지한다.

원본 이름은 `/models/wrist/manifest.json`에 보존한다. 3D 렌더용 메시와 해석용 사면체 메시는 별도 자산으로 만들되, 원본 좌표와 대응 지도를 공유한다. 절단면의 현재 지방·근섬유·격막은 대표 조직 패턴이며 실제 histology texture가 아니다. 원본 표면에서 유도한 지방 경계에 개인별 지방 두께를 부여하는 것은 초기 근사이며 자기교차·조직 충돌 검증 후 실제 체적 분할로 교체한다.

추가 해상도 목표(설계): 혈관벽 주변 0.1–0.3 mm, 접촉 패드 아래 0.2–0.5 mm의 해석 요소를 출발점으로 수렴 시험한다. 이 값은 검증을 거친 충분 조건이 아니다. 화면 LOD를 높여도 해석 메시 수렴을 대신하지 못한다.

## 피험자별 수집 기록

좌/우, 손잡이, 정확한 crease 기준 거리, 전완 회내/회외 각도, 손목 굴곡/신전, 피부 온도, 패치 preload, 초음파 탐촉자 압박, ECG 동기, 동맥 내경·벽·깊이·곡률, FCR/BR/요골 상대 위치, 피부와 지방 경계, 근육 수축 단계, 검지 Red/IR LED/PD 위치를 기록한다. 혈관 직경은 적어도 이완기·수축기 프레임을 분리하고 probe 압박에 따른 깊이 편향을 남긴다.
