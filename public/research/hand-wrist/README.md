# SOMA 개발 기록과 손·손목 바이오센싱 확장 설계

기준일: 2026-09-13. 작업 코드: `body_3d/web`. 비교 대상: `cbp_algorithm/research/digital-twin` 및 `cbp_sensing/beamforming/core`.

SOMA는 그리스어 σῶμα, ‘몸’을 뜻한다. 별도 약어로 정의하지 않았다.

이 기록은 대화의 요청, Git 이력, 실행 코드, 문헌을 구분한다. ‘구현’은 가상 연구 기능을 뜻하며 환자별 해부학 정확도나 혈압·SpO₂ 임상 성능 검증을 뜻하지 않는다.

## 현재 실행되는 것

- `/`는 시뮬레이터 썸네일과 기능 소개, 상단 메뉴는 전신·손목·연구 기록·사용 매뉴얼로 이동한다.
- `/manual`은 화면 조작과 macOS·Windows·Linux 로컬 데모 설치 안내를 제공한다. 설치·실행 스크립트와 별도 데모 패키징을 지원하며 실제 OS별 검증 범위는 소스의 `docs/operations/demo-validation.md`에 기록한다.
- 기존 전신 화면은 `/simulators/body`로 이동했다. 기존 해부학·센서·동작 기능을 유지한다.
- `/simulators/wrist`는 기존 CBP 웹 엔진을 독립 모듈로 연결한다. MRC, 국소 지연, PPG/SpO₂, BP 추정 비교와 패치 배치 UI를 유지했다.
- 기하 도형으로 구성된 전신 아바타를 SOMA의 실제 전신 메시와 관절 리그로 교체했다.
- 손목은 같은 아틀라스에서 오른손·원위 전완을 추출했다. 뼈 29개, 근육·힘줄·근막 등 52개, 혈관 23개, 신경 22개 이름 붙은 구조가 포함된다. 이것은 메시 항목 수이며 조직학적 구조의 완전성을 뜻하지 않는다.
- 피부 외형, 해부학 레이어, 3D 조직 단면, 표면 등고선 모드가 있다. 지방 경계는 피부에서 유도한 대표층이며 지방 MRI 분할 결과가 아니다.
- 동맥 압력 → 반경 변화 → 인과적 조직 이완 → 전극 면적에 따른 정전용량 변화가 샘플 생성 경로에 들어갔다. 반경·표면 변위가 화면으로 전달된다. 표시 확대 ×1–8은 신호에 곱하지 않는다.
- 두 저장소 원본 중 CBP 참조 디렉터리는 수정하지 않았다. 앱 내부 `public/simulators/radial`에 가져온 코드와 변경 사항을 격리했다. 원본 파일 해시는 `source-manifest.json`에 남겼다.

## 다음 단계인 것

피험자별 초음파/MRI 정합, 실제 피하지방·힘줄 체적 분할, 비선형 접촉 FEM, 광학 Monte Carlo 검증, 주파수별 MVDR의 웹 코어 이식, 실제 ECG 취득 프레임과 PEP 분리, 독립 임상 데이터의 BP·SpO₂ 검증. 이 문서의 설계가 곧 구현 완료 또는 임상 검증 완료를 뜻하지 않는다.
