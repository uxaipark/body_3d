# Feature History

A summary of changes in the public simulator.

| Area | Implemented features |
| --- | --- |
| Whole-body anatomy | Separate skeletal, muscular, circulatory, respiratory, neural and skin displays |
| Surface and motion | Atlas skin, joint rig, locomotion and support-surface contact |
| Physiological deformation | Cardiac contraction/relaxation, arterial pulsation, respiratory organ/tissue motion |
| Clinical tasks | Standing, repeated sit-to-stand, grip and bed transfer |
| Skin sections | Regional structures, surface contours, local deformation and optical display |
| Wrist sensing | Curved patch, artery position/depth, connected vessels and surrounding displacement |
| Interaction | Vessel-axis rotation, edge tilting and camera/display reset |
| Documentation | Research and guide web reader with UTF-8 downloads |
| Languages | Korean and English interfaces and documents |

Improved shape and synthetic signals do not establish patient-specific material properties or clinical accuracy.
