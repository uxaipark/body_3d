# 기능 변경 요약

현재 공개 시뮬레이터의 주요 기능 변화를 요약합니다.

| 영역 | 반영된 기능 |
| --- | --- |
| 전신 해부학 | 골격·근육·순환·호흡·신경·피부의 계통별 표시 |
| 외피와 동작 | 아틀라스 피부, 관절 리그, 보행·달리기와 지지면 접촉 |
| 생리적 변형 | 심장 수축·이완, 동맥 맥동, 호흡에 따른 장기·조직 변위 |
| 임상 작업 | 일어서기·반복 앉았다 일어서기·손 쥐기·침대 이동 |
| 피부 단면 | 부위별 조직 구조, 표면 등고선, 국소 변형과 광학 표시 |
| 손목 센싱 | 곡면 패치, 요골동맥 위치·깊이 조절, 연결된 혈관과 주변 변위 |
| 조작 | 동맥 길이축 회전, 상하단 기울이기, 카메라·표시 설정 초기화 |
| 문서 | 연구 기록·사용 매뉴얼의 웹 보기와 UTF-8 다운로드 |

형상과 합성 신호의 개선은 환자별 물성이나 임상 정확도 검증을 뜻하지 않습니다.
